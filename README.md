# Sobre o Projeto

O **Bicicleta POO Python** é um projeto educacional criado para praticar conceitos fundamentais de orientação a objetos utilizando Python.

A aplicação representa uma bicicleta como um objeto, permitindo executar ações como:

- Buzinar
- Parar
- Correr
- Trocar marcha

Além disso, o projeto demonstra conceitos importantes de modelagem orientada a objetos, como encapsulamento, criação de métodos e manipulação de atributos.

---

# Funcionalidades

- Criação de objetos da classe `Bicicleta`
- Definição de atributos:
  - Cor
  - Modelo
  - Ano
  - Valor
  - Aro
- Métodos de comportamento:
  - `buzinar()`
  - `parar()`
  - `correr()`
  - `trocar_marcha()`
- Representação personalizada do objeto com `__str__`
- Interação via terminal
